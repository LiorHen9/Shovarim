# מקרי בדיקה לצ'אטבוט

תיעוד ידני של תרחישי שיחה מול הצ'אטבוט (`src/lib/mcp/systemPrompt.ts` + `src/lib/mcp/agentLoop.ts`), עם ההתנהגות הצפויה וההרצה בפועל. **אין כאן test runner אוטומטי** — כל מקרה מורץ ידנית מול קריאת Claude אמיתית, ונבדק בעין. הרצה חוזרת רלוונטית בעיקר אחרי שינוי ב-system prompt, כדי לוודא שהתנהגות קיימת לא נשברה.

## איך מריצים מקרה בדיקה

1. להריץ Firestore emulator: `npx firebase emulators:start --only firestore`.
2. לוודא `.env.local` מכיל `ANTHROPIC_API_KEY` ו-`FIREBASE_USE_EMULATOR=true` (מצביע על ה-emulator).
3. `npm run chat:scenario -- docs/chatbot-test-cases/<file>.json` — קובץ ה-JSON הוא מערך של הודעות משתמש עוקבות (תור שיחה יחיד), מורצות נגד uid סינתטי חדש (בלי כרטיסים/רשימות קיימים).

כל מקרה בדיקה חדש: להוסיף קובץ JSON תואם תחת `docs/chatbot-test-cases/`, ולתעד אותו כאן.

## מקרי בדיקה

### שובר שמומש דרך אפליקציה, לא קוד — "תו זהב" (מכבי)

**קובץ:** `docs/chatbot-test-cases/app-phone-redemption.json`

**רקע:** הודעת SMS אמיתית שמודיעה על שובר, אך המימוש בה אינו באמצעות קוד/ברקוד בתוך ההודעה — אלא דרך הורדת אפליקציה והתחברות אליה עם מספר הטלפון שקיבל את ההודעה. זו תבנית כללית (לא ספציפית ל"תו זהב"/מכבי) שהצ'אטבוט צריך לזהות: כשאין קוד מפורש, ה"מזהה" הרלוונטי למימוש הוא מספר הטלפון.

**הודעה 1 (מודבקת מהמשתמש):**
```
גב פולינה חן, מכבי מאחלת לך ולבני משפחתך שנה טובה, ושמחים להעניק לך  680 ₪ שי לחג

קיבלת תו זהב סלולרי למימוש מעל 100 רשתות! יש להיכנס מטלפון זה לקישור המצורף ולהוריד את אפליקציית תו הזהב. לאחר ההורדה יש להתחבר לאפליקציה עם מספר הנייד שאליו נשלחה ההודעה. אם המספר אינו מחובר לאפליקציה, יש לפנות לארגון שממנו התקבל התו לצורך הזדהות. https://bl2.co/BS8UjrFVVAEV
```

**הודעה 2 (תשובת המשתמש לשאלת הבהרה):** `המספר הוא 050-1234567. אפשר לאשר.`

**התנהגות צפויה:**
- הבוט מזהה שאין קוד/ברקוד מפורש בהודעה, ושהמימוש תלוי במספר הטלפון + אפליקציה.
- לפני הצגת תמצית/יצירת כרטיס — שואל במפורש לאיזה מספר טלפון הונפק השובר.
- לאחר קבלת המספר — מציג תמצית אחת (לפי הפורמט הקבוע, שורה לכל שדה), עם שדה `notes` שכולל את מספר הטלפון ואת העובדה שהמימוש דרך אפליקציה (לא קוד), ומבקש אישור לפני `createCard`.

**נבדק בפועל: 2026-08-30**

לפני כיוונון ה-system prompt (baseline): הבוט חילץ את כל שאר השדות נכון, אך **לא** שאל על מספר הטלפון — פשוט העתיק את נוסח ההודעה ("יש להתחבר לאפליקציה עם מספר הטלפון שקיבל את ההודעה") לשדה ההערות כטקסט כללי, בלי לפתור אותו למספר קונקרטי.

לאחר הוספת הנחיה ייעודית ל-`src/lib/mcp/systemPrompt.ts` (זיהוי תבנית "מימוש מבוסס אפליקציה/טלפון" כשאין קוד מפורש בהודעה): הבוט שאל במפורש "לאיזה מספר טלפון נשלח השובר הזה?", ולאחר התשובה כלל בשדה ההערות: `מימוש דרך אפליקציית תו הזהב, התחברות עם מספר טלפון 050-1234567 (השובר הונפק ע"י מכבי לרגל ראש השנה)` — תואם את הציפייה.
